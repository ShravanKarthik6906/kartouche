What Rosetta takes care of

Keeps the formatting

Bold and italic words mid-sentence, lists, tables and callouts stay styled. Each sentence is translated as a whole, so grammar comes out right.

Fits the layout

Translations often run long. Rosetta measures text with real font metrics against each frame, then re-wraps, shrinks slightly or shortens the wording, and flags anything it can't fit.

Right-to-left ready

Arabic stories are flipped to right-to-left and set in an Arabic font, which is packaged with the file so it shows up correctly in InDesign.

Checks its own work

A QA report lists anything untranslated, translated inconsistently, or too long for its frame, with the page it's on.
